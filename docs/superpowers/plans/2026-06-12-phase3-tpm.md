# Phase 3 — TPM 2.0 Attestation (Key Residency) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the `tpm-attest` backend — a non-extractable ECDSA P-256 device-attestation key that is generated inside, never leaves, and signs inside a TPM 2.0 — behind the exact same FFI/Python contract the soft backend already satisfies, so the cert/handshake/server flow is unchanged.

**Architecture:** A new `device_attest_tpm.rs` (`#[cfg(feature = "tpm-attest")]`) exposes a `TpmAttestKey` with the SoftAttestKey method surface plus no-op-passphrase `encrypt_to_store`/`decrypt_from_store` shims, so `lib.rs` needs no `cfg` branching. The private key is created with `TPM2_Create` under a deterministically re-derivable Owner-hierarchy primary using a `sign | fixedTPM | fixedParent` P-256 template; the persistable artifact is a versioned `DSMT` context blob (`TPM2B_PUBLIC` marshalled + raw `TPM2B_PRIVATE` buffer) that loads only on the TPM that created it. The CSR is built in Python (`enroll.py`) from the TPM-exported SPKI with the signature delegated to the TPM — no new dependency.

**Tech Stack:** Rust (`tss-esapi` 7.7.0, optional, gated by `tpm-attest`; pregenerated bindings via `tss-esapi-sys` 0.6.0, no bindgen), `p256` (test-only independent verifier), PyO3 0.24; Python (`cryptography` 46.x for CSR assembly, pytest); swtpm 0.7.1 + `libtss2-tcti-swtpm` for hermetic tests.

## Build & test matrix

This is the single most important up-front concept: **the two attest backends are mutually exclusive at compile time** (`device_attest.rs` `compile_error!` guard fires if both or neither feature is on). One installed `tuncore` wheel therefore carries exactly ONE backend. The soft tests need a soft wheel; the TPM tests need a TPM wheel. We never edit a pre-existing test; we route each test to the build that satisfies its import.

| Lane | Cargo invocation | `ATTEST_BACKEND_IS_SOFTWARE` | Runs |
|---|---|---|---|
| Soft Rust unit | `cargo test --manifest-path rust/tuncore/Cargo.toml --no-default-features --features dev-soft-attest` | n/a (Rust) | `device_attest_soft` inline tests (unchanged), `passphrase_store` tests |
| TPM Rust integration | `cargo test --manifest-path rust/tuncore/Cargo.toml --no-default-features --features tpm-attest --test tpm_swtpm` + `--test dsmt_format` | n/a (Rust) | swtpm harness, DSMT format, generate/sign/store/residency/csr (Task 3.2–3.8) |
| Soft Python | build soft wheel → `pytest` (env `DSM_REQUIRE_TUNCORE=1`) | `True` | `test_attest.py`, `test_stores.py`, `test_attest_gate.py`, etc. (unchanged) |
| TPM Python | build TPM wheel → `pytest tests/test_tpm_*.py` under swtpm fixture | `False` | new TPM-only Python tests (Task 3.10) |

**Why two wheels, not one:** `maturin build --no-default-features --features <backend>` produces a backend-specific wheel. CI runs the soft lane and the TPM lane as **separate jobs** with separate wheels (Task 3.11). Existing Python tests that exercise soft-attest already gate on `ATTEST_BACKEND_IS_SOFTWARE` / `_HAS_TUNCORE`; under the TPM wheel they self-skip (a marker in the new `tests/conftest.py` fixture keys on the constant — Task 3.10). New TPM Python tests skip under the soft wheel the same way. **No existing test file is modified.**

**Default flip timing:** Tasks 3.1–3.10 keep `default = ["dev-soft-attest"]` so the soft suite stays green throughout development and every TPM lane is opt-in via explicit `--no-default-features --features tpm-attest`. Task 3.11 flips `default = ["tpm-attest"]` last, after the backend is proven, and adds the swtpm CI job.

**swtpm TCTI is TCP, not unix-socket (verified).** tss-esapi 7.7.0's `TctiNameConf::Swtpm(NetworkTPMConfig)` only carries `host` + `port` — there is NO unix-socket path variant. The harness therefore runs swtpm with TCP channels (`--server type=tcp,port=N --ctrl type=tcp,port=N+1`) and points tss-esapi at `swtpm:host=127.0.0.1,port=N`. The swtpm/mssim TCTI convention uses `port` for the command channel and `port+1` for the control channel automatically.

**Verified API facts baked into this plan (do not re-derive):**
- `tss-esapi` 7.7.0 is in the cargo cache; `tss-esapi-sys` 0.6.0 ships pregenerated bindings for `x86_64-unknown-linux-gnu` (build.rs panics only for unsupported tuples; x86_64-linux is supported → no libclang/bindgen for the default build).
- `Context::new(TctiNameConf) -> Result<Context>`; `ctx.startup(StartupType::Clear)`; `ctx.get_random(n) -> Result<Digest>`.
- `ctx.execute_with_nullauth_session(|ctx| { ... })` wraps create_primary/create/load/sign in an HMAC session with empty auth (the TPM Owner empty-auth + key empty-auth path).
- `ctx.create_primary(Hierarchy::Owner, public, None, None, None, None) -> CreatePrimaryKeyResult` (`.key_handle`, `.out_public`).
- `ctx.create(parent: KeyHandle, public, None, None, None, None) -> CreateKeyResult` (`.out_private: Private`, `.out_public: Public`).
- `ctx.load(parent: KeyHandle, private: Private, public: Public) -> KeyHandle`.
- `ctx.sign(key: KeyHandle, digest: Digest, scheme: SignatureScheme, validation: HashcheckTicket) -> Signature`; use `SignatureScheme::EcDsa { hash_scheme: HashScheme::new(HashingAlgorithm::Sha256) }` and `HashcheckTicket::Null` (free signing of an externally supplied digest is allowed because the key is unrestricted).
- `Signature::EcDsa(EccSignature)`; `EccSignature::signature_r()/signature_s() -> &EccParameter`; `EccParameter::value() -> &[u8]`.
- `Public::marshall() -> Result<Vec<u8>>` (TPMT_PUBLIC) and `Public::unmarshall(&[u8]) -> Result<Public>`; **`Private` has NO `Marshall` impl** — persist via `private.value().to_vec()` and restore via `Private::try_from(&[u8])` (exactly how tss-esapi's own transient abstraction persists keys).
- `Public::try_from(Public) -> PublicKey::Ecc { x, y }` exposes the raw uncompressed point for SPKI assembly.
- Parent template: `PublicEccParametersBuilder::new_restricted_decryption_key(SymmetricDefinitionObject::AES_128_CFB, EccCurve::NistP256)`.
- Child template: `PublicEccParametersBuilder::new_unrestricted_signing_key(EccScheme::EcDsa(HashScheme::new(HashingAlgorithm::Sha256)), EccCurve::NistP256)`.
- `ObjectAttributesBuilder` methods: `with_fixed_tpm`, `with_fixed_parent`, `with_sensitive_data_origin`, `with_user_with_auth`, `with_sign_encrypt`, `with_decrypt`, `with_restricted`, `with_encrypted_duplication`, `build()`.
- Q4 (verified end-to-end in Python): `cryptography`'s `CertificateSigningRequestBuilder.sign()` needs a private key, but `csr.tbs_certrequest_bytes` exposes the `CertificationRequestInfo`. P-256 SPKI is a fixed 91 bytes and appears exactly once in the TBS, so substituting the throwaway SPKI with the TPM SPKI yields the correct TBS; the TPM signs it; Python assembles `SEQUENCE { TBS, AlgorithmIdentifier(ecdsa-with-SHA256), BIT STRING sig }`. Re-parse + `is_signature_valid` confirmed True. **No new dependency.**

```rust
//! swtpm-backed integration tests for the TPM attest backend.
//!
//! Every test runs against a per-test swtpm instance over TCP (the swtpm
//! TCTI in tss-esapi 7.7.0 supports host+port only — no unix socket). The
//! real host /dev/tpm0 is NEVER touched.
#![cfg(feature = "tpm-attest")]

use std::net::TcpListener;
use std::path::PathBuf;
use std::process::{Child, Command};
use std::str::FromStr;
use std::time::{Duration, Instant};

use tss_esapi::interface_types::reserved_handles::Hierarchy;
use tss_esapi::tcti_ldr::TctiNameConf;
use tss_esapi::Context;

/// RAII swtpm instance. Kills the child + removes the state dir on drop.
pub struct Swtpm {
    child: Child,
    state_dir: PathBuf,
    pub tcti: String,
}

fn free_port() -> u16 {
    // Bind :0 to let the OS pick a free port, then release it. swtpm uses
    // `port` (command) and `port+1` (control); we reserve a pair by picking
    // an even-ish port and trusting the small race window (tests are serial
    // enough; if flaky, retry-loop here).
    let l = TcpListener::bind("127.0.0.1:0").expect("bind ephemeral");
    let p = l.local_addr().unwrap().port();
    drop(l);
    p
}

impl Swtpm {
    pub fn start() -> Self {
        let state_dir = std::env::temp_dir().join(format!("dsm-swtpm-{}", std::process::id().wrapping_add(rand_u32())));
        std::fs::create_dir_all(&state_dir).expect("mk state dir");
        let port = free_port();
        let ctrl = port + 1;
        let child = Command::new("swtpm")
            .arg("socket")
            .arg("--tpm2")
            .arg("--flags").arg("not-need-init")
            .arg("--tpmstate").arg(format!("dir={}", state_dir.display()))
            .arg("--server").arg(format!("type=tcp,port={port},bindaddr=127.0.0.1"))
            .arg("--ctrl").arg(format!("type=tcp,port={ctrl},bindaddr=127.0.0.1"))
            .spawn()
            .expect("spawn swtpm (is it installed?)");
        let tcti = format!("swtpm:host=127.0.0.1,port={port}");
        // Wait for the data port to accept connections.
        let deadline = Instant::now() + Duration::from_secs(5);
        while std::net::TcpStream::connect(("127.0.0.1", port)).is_err() {
            if Instant::now() > deadline {
                panic!("swtpm did not come up on port {port}");
            }
            std::thread::sleep(Duration::from_millis(20));
        }
        Self { child, state_dir, tcti }
    }

    pub fn context(&self) -> Context {
        let mut ctx = Context::new(TctiNameConf::from_str(&self.tcti).expect("parse tcti"))
            .expect("esys context over swtpm");
        // Bring the TPM up; ignore "already initialised" if a prior call ran.
        let _ = ctx.startup(tss_esapi::constants::StartupType::Clear);
        ctx
    }
}

impl Drop for Swtpm {
    fn drop(&mut self) {
        let _ = self.child.kill();
        let _ = self.child.wait();
        let _ = std::fs::remove_dir_all(&self.state_dir);
    }
}

// Tiny non-crypto RNG for the temp-dir suffix (avoids pulling rand into the
// test's direct deps beyond what tuncore already provides).
fn rand_u32() -> u32 {
    use std::time::{SystemTime, UNIX_EPOCH};
    SystemTime::now().duration_since(UNIX_EPOCH).unwrap().subsec_nanos()
}

#[test]
fn swtpm_get_random_works() {
    let tpm = Swtpm::start();
    let mut ctx = tpm.context();
    let bytes = ctx.get_random(16).expect("get_random over swtpm");
    assert_eq!(bytes.value().len(), 16);
    // A second draw differs (sanity, not a statistical test).
    let bytes2 = ctx.get_random(16).expect("get_random 2");
    assert_ne!(bytes.value(), bytes2.value());
    // Owner hierarchy is reachable (empty-auth path) — a cheap capability
    // call would also work; get_random suffices as plumbing proof.
    let _ = Hierarchy::Owner;
}
```

Mirror `passphrase_store`'s discipline: magic + version + typed-error rejection of unknown header bytes *before* any TPM call. Layout (from the architecture §4.4):

```
 0   4   magic = b"DSMT"
 4   1   format_version = 0x01
 5   1   hierarchy   (0x01 = OWNER)
 6   1   key_kind    (0x01 = CONTEXT_BLOB)
 7   1   curve_id    (0x01 = NIST_P256)
 8   2BE pub_len
 10  N   marshalled TPMT_PUBLIC
 10+N 2BE priv_len
 12+N M  TPM2B_PRIVATE buffer bytes (Private::value())
```

```rust
//! Versioned, TPM-free `DSMT` context-blob format.
//!
//! The blob carries no usable secret (the TPM2B_PRIVATE sensitive area is
//! TPM-encrypted), so no AEAD is needed. `TPM2_Load` is itself the
//! integrity check on the private area. The header bytes are validated
//! *before* any TPM call, exactly as `passphrase_store` validates its DSMK
//! header, so a tampered header fails closed with a typed error.

const MAGIC: &[u8; 4] = b"DSMT";
const VERSION_1: u8 = 0x01;
const HIERARCHY_OWNER: u8 = 0x01;
const KEY_KIND_CONTEXT_BLOB: u8 = 0x01;
const CURVE_NIST_P256: u8 = 0x01;
const HEADER_LEN: usize = 8;

/// Parsed DSMT payload: the marshalled TPMT_PUBLIC and the raw TPM2B_PRIVATE
/// buffer bytes (`Private::value()`).
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct DsmtBlob {
    pub public_tpmt: Vec<u8>,
    pub private_buf: Vec<u8>,
}

/// Typed parse failures. All are detected before any TPM interaction.
#[derive(Clone, Debug, PartialEq, Eq)]
pub enum DsmtError {
    BadMagic,
    UnsupportedVersion(u8),
    UnknownHierarchy(u8),
    UnknownKeyKind(u8),
    UnknownCurve(u8),
    Truncated,
    TrailingBytes,
}

impl std::fmt::Display for DsmtError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            DsmtError::BadMagic => write!(f, "DSMT blob: bad magic (not a TPM attest blob)"),
            DsmtError::UnsupportedVersion(v) => write!(f, "DSMT blob: unsupported version {v}"),
            DsmtError::UnknownHierarchy(h) => write!(f, "DSMT blob: unknown hierarchy byte {h}"),
            DsmtError::UnknownKeyKind(k) => write!(f, "DSMT blob: unknown key_kind byte {k}"),
            DsmtError::UnknownCurve(c) => write!(f, "DSMT blob: unknown curve byte {c}"),
            DsmtError::Truncated => write!(f, "DSMT blob: truncated"),
            DsmtError::TrailingBytes => write!(f, "DSMT blob: trailing bytes after payload"),
        }
    }
}

/// Serialize a `DsmtBlob` to the versioned on-disk form. Infallible: the
/// length fields are bounded by the caller's own marshalled sizes (TPM2B
/// structures are well under u16::MAX).
#[must_use]
pub fn serialize(blob: &DsmtBlob) -> Vec<u8> {
    let mut out = Vec::with_capacity(
        HEADER_LEN + 2 + blob.public_tpmt.len() + 2 + blob.private_buf.len(),
    );
    out.extend_from_slice(MAGIC);
    out.push(VERSION_1);
    out.push(HIERARCHY_OWNER);
    out.push(KEY_KIND_CONTEXT_BLOB);
    out.push(CURVE_NIST_P256);
    // Lengths are bounded by TPM2B max (<= 0xFFFF); cast is lossless. A
    // debug_assert documents the invariant for any future larger structure.
    debug_assert!(blob.public_tpmt.len() <= u16::MAX as usize);
    debug_assert!(blob.private_buf.len() <= u16::MAX as usize);
    #[allow(clippy::cast_possible_truncation)]
    out.extend_from_slice(&(blob.public_tpmt.len() as u16).to_be_bytes());
    out.extend_from_slice(&blob.public_tpmt);
    #[allow(clippy::cast_possible_truncation)]
    out.extend_from_slice(&(blob.private_buf.len() as u16).to_be_bytes());
    out.extend_from_slice(&blob.private_buf);
    out
}

/// Parse + validate. Rejects unknown header bytes with a typed error before
/// the caller touches the TPM.
///
/// # Errors
/// Returns a [`DsmtError`] on any header mismatch, length overrun, or
/// trailing garbage.
pub fn parse(bytes: &[u8]) -> Result<DsmtBlob, DsmtError> {
    if bytes.len() < HEADER_LEN {
        return Err(DsmtError::Truncated);
    }
    if &bytes[0..4] != MAGIC {
        return Err(DsmtError::BadMagic);
    }
    if bytes[4] != VERSION_1 {
        return Err(DsmtError::UnsupportedVersion(bytes[4]));
    }
    if bytes[5] != HIERARCHY_OWNER {
        return Err(DsmtError::UnknownHierarchy(bytes[5]));
    }
    if bytes[6] != KEY_KIND_CONTEXT_BLOB {
        return Err(DsmtError::UnknownKeyKind(bytes[6]));
    }
    if bytes[7] != CURVE_NIST_P256 {
        return Err(DsmtError::UnknownCurve(bytes[7]));
    }
    let mut off = HEADER_LEN;
    let pub_len = read_u16(bytes, &mut off)? as usize;
    let public_tpmt = read_slice(bytes, &mut off, pub_len)?;
    let priv_len = read_u16(bytes, &mut off)? as usize;
    let private_buf = read_slice(bytes, &mut off, priv_len)?;
    if off != bytes.len() {
        return Err(DsmtError::TrailingBytes);
    }
    Ok(DsmtBlob { public_tpmt, private_buf })
}

fn read_u16(bytes: &[u8], off: &mut usize) -> Result<u16, DsmtError> {
    let end = off.checked_add(2).ok_or(DsmtError::Truncated)?;
    if end > bytes.len() {
        return Err(DsmtError::Truncated);
    }
    let v = u16::from_be_bytes([bytes[*off], bytes[*off + 1]]);
    *off = end;
    Ok(v)
}

fn read_slice(bytes: &[u8], off: &mut usize, len: usize) -> Result<Vec<u8>, DsmtError> {
    let end = off.checked_add(len).ok_or(DsmtError::Truncated)?;
    if end > bytes.len() {
        return Err(DsmtError::Truncated);
    }
    let v = bytes[*off..end].to_vec();
    *off = end;
    Ok(v)
}

fn open_context(tcti: &str) -> Result<Context, String> {
    let conf = TctiNameConf::from_str(tcti).map_err(|_| {
        format!("invalid TPM TCTI {tcti:?}; expected e.g. device:/dev/tpmrm0")
    })?;
    let mut ctx = Context::new(conf)
        .map_err(|e| map_tpm_err("open TPM context", e, tcti))?;
    // swtpm needs an explicit startup; a hardware TPM is already started, in
    // which case the RC is INITIALIZE and is benign.
    if let Err(e) = ctx.startup(StartupType::Clear) {
        // Only swallow the "already initialised" case; surface anything else.
        if !is_already_initialized(&e) {
            return Err(map_tpm_err("TPM2_Startup", e, tcti));
        }
    }
    Ok(ctx)
}

    /// Provision a NEW attest key using the default production TCTI.

    /// is leaked beyond the return-code name) on any TPM error.
    pub fn generate() -> Result<Self, String> {
        let tcti = resolve_tcti(None);
        Self::generate_with_tcti(&tcti)
    }

    /// Provision a NEW attest key against an explicit TCTI (tests pass the
    /// swtpm TCTI here; production uses `generate`).
    pub fn generate_with_tcti(tcti: &str) -> Result<Self, String> {
        let mut ctx = open_context(tcti)?;
        // The closure error is `TpmOpError` (satisfies `E: From<Error>`); we
        // map `String`-returning template helpers via `TpmOpError::from` and
        // convert the whole result back to `String` at the `?` boundary.
        let (key_handle, child_public, child_private) = ctx
            .execute_with_nullauth_session(|ctx| -> Result<_, TpmOpError> {
                let parent = ctx.create_primary(
                    Hierarchy::Owner,
                    parent_template().map_err(TpmOpError::from)?,
                    None, None, None, None,
                )?;
                let created = ctx.create(
                    parent.key_handle,
                    child_template().map_err(TpmOpError::from)?,
                    None, None, None, None,
                )?;
                let out_private = created.out_private.clone();
                let key_handle = ctx.load(
                    parent.key_handle,
                    created.out_private,
                    created.out_public.clone(),
                )?;
                // Parent no longer needed once the child is loaded — flush it
                // to keep transient-slot pressure to one handle.
                ctx.flush_context(parent.key_handle.into())?;
                Ok((key_handle, created.out_public, out_private))
            })
            .map_err(|e: TpmOpError| e.0)?;
        let spki_der = spki_from_public(&child_public)?;
        Ok(Self { ctx: RefCell::new(ctx), key_handle, child_public, child_private, spki_der })
    }

    /// SubjectPublicKeyInfo DER of the in-TPM key. `Err` once zeroized.
    pub fn public_spki_der(&self) -> Result<&[u8], String> {
        if self.spki_der.is_empty() {
            return Err("attest key has been zeroized".into());
        }
        Ok(&self.spki_der)
    }

    /// The child key's object attributes — used by tests to lock the

    /// getter (verified present in 7.7.0) rather than manual destructuring.

/// Resolve the TCTI per the precedence in the architecture §7.3:
/// explicit arg (config) > TPM2TOOLS_TCTI/TCTI env > device:/dev/tpmrm0.
fn resolve_tcti(config_tcti: Option<&str>) -> String {
    if let Some(t) = config_tcti {
        return t.to_string();
    }
    if let Ok(t) = std::env::var("TPM2TOOLS_TCTI") {
        if !t.is_empty() {
            return t;
        }
    }
    if let Ok(t) = std::env::var("TCTI") {
        if !t.is_empty() {
            return t;
        }
    }
    DEFAULT_TCTI.to_string()
}

/// Build an SPKI DER from a TPM `Public` ECC point using `p256`/`sec1`
/// machinery already in tree (test+prod: `p256` is in `dev-soft-attest`;
/// for the tpm build we add it as a tpm-attest dep — see Task 3.5 note).
fn spki_from_public(public: &Public) -> Result<Vec<u8>, String> {
    use tss_esapi::abstraction::public::PublicKey;
    let pk = PublicKey::try_from(public.clone())
        .map_err(|e| format!("extract TPM public point: {e}"))?;
    let (x, y) = match pk {
        PublicKey::Ecc { x, y } => (x, y),
        _ => return Err("attest key is not ECC".into()),
    };
    // Uncompressed SEC1 point: 0x04 || X(32) || Y(32). TPM may emit shorter
    // big-endian coordinates with leading zeros stripped; left-pad to 32.
    let mut point = Vec::with_capacity(65);
    point.push(0x04);
    point.extend_from_slice(&left_pad32(&x));
    point.extend_from_slice(&left_pad32(&y));
    let vk = p256::ecdsa::VerifyingKey::from_sec1_bytes(&point)
        .map_err(|e| format!("TPM point is not a valid P-256 key: {e}"))?;
    use p256::pkcs8::EncodePublicKey;
    Ok(vk
        .to_public_key_der()
        .map_err(|e| format!("encode SPKI DER: {e}"))?
        .as_bytes()
        .to_vec())
}

fn left_pad32(b: &[u8]) -> [u8; 32] {
    let mut out = [0u8; 32];
    let n = b.len().min(32);
    out[32 - n..].copy_from_slice(&b[b.len() - n..]);
    out
}

/// Map a tss-esapi error to a `String` without leaking internal TPM state

fn map_tpm_err(op: &str, e: tss_esapi::Error, tcti: &str) -> String {
    format!("{op} failed on TPM at {tcti}: {e}")
}

fn is_already_initialized(e: &tss_esapi::Error) -> bool {
    // TPM_RC_INITIALIZE is returned by Startup on an already-started TPM.

}

    /// assemble ASN.1 DER ECDSA `(r, s)` — same output contract as the soft
    /// backend. Enforces the 1 MiB cap (parity with soft L-CRYPT-3). Takes

    /// Esys context mutably from the `RefCell`.

/// Uses `p256`'s `Signature` so the DER is byte-for-byte what the verifier
/// (cryptography's ECDSA verify) and the soft backend produce.
fn ecdsa_sig_to_der(sig: &tss_esapi::structures::Signature) -> Result<Vec<u8>, String> {
    let ecc = match sig {
        tss_esapi::structures::Signature::EcDsa(e) => e,
        _ => return Err("TPM returned a non-ECDSA signature".into()),
    };
    let r = left_pad32(ecc.signature_r().value());
    let s = left_pad32(ecc.signature_s().value());
    let mut scalars = [0u8; 64];
    scalars[..32].copy_from_slice(&r);
    scalars[32..].copy_from_slice(&s);
    let signature = p256::ecdsa::Signature::from_slice(&scalars)
        .map_err(|e| format!("invalid ECDSA (r,s) from TPM: {e}"))?;
    Ok(signature.to_der().as_bytes().to_vec())
}
```

    /// (marshalled TPMT_PUBLIC + raw TPM2B_PRIVATE buffer + header). No
    /// passphrase — the key is in the TPM, not a sealed scalar.
    pub fn to_store_blob(&self) -> Result<Vec<u8>, String> {
        use tss_esapi::traits::Marshall;
        let public_tpmt = self
            .child_public
            .marshall()
            .map_err(|e| format!("marshall TPMT_PUBLIC: {e}"))?;
        // `Private` has no Marshall impl in tss-esapi 7.7.0; persist the raw
        // TPM2B_PRIVATE buffer bytes via `.value()` and restore with
        // `Private::try_from(&[u8])` — exactly how tss-esapi's own transient
        // abstraction persists keys.

        Ok(tpm_blob::serialize(&DsmtBlob { public_tpmt, private_buf }))

    /// Reconstitute from a `DSMT` blob using the default production TCTI.
    pub fn from_store_blob(blob: &[u8]) -> Result<Self, String> {
        let tcti = resolve_tcti(None);
        Self::from_store_blob_with_tcti(blob, &tcti)

    /// Reconstitute from a `DSMT` blob against an explicit TCTI. Validates the
    /// header BEFORE any TPM call, recreates the deterministic primary,
    /// `TPM2_Load`s the child, flushes the parent, caches SPKI.
    pub fn from_store_blob_with_tcti(blob: &[u8], tcti: &str) -> Result<Self, String> {
        use tss_esapi::traits::UnMarshall;
        // Header validation first — typed error, no TPM interaction yet.
        let parsed = tpm_blob::parse(blob).map_err(|e| e.to_string())?;
        let child_public = Public::unmarshall(&parsed.public_tpmt)
            .map_err(|e| format!("unmarshall TPMT_PUBLIC: {e}"))?;
        let child_private = tss_esapi::structures::Private::try_from(parsed.private_buf)
            .map_err(|e| format!("rebuild TPM2B_PRIVATE: {e}"))?;
        let mut ctx = open_context(tcti)?;
        let load_pub = child_public.clone();
        let load_priv = child_private.clone();
        let key_handle = ctx
            .execute_with_nullauth_session(|ctx| -> Result<_, TpmOpError> {
                let parent = ctx.create_primary(
                    Hierarchy::Owner,
                    parent_template().map_err(TpmOpError::from)?,
                    None, None, None, None,
                )?;
                // The most common load failure is a wrong-TPM blob (residency)
                // or a cleared TPM; the outer `?` boundary annotates it.
                let key_handle = ctx.load(parent.key_handle, load_priv, load_pub)?;
                ctx.flush_context(parent.key_handle.into())?;
                Ok(key_handle)
            })
            .map_err(|e: TpmOpError| {
                format!(
                    "{} (attest blob does not load on this TPM: different/cleared \
                     TPM, or corrupt blob — re-enroll)",
                    e.0
                )
            })?;
        let spki_der = spki_from_public(&child_public)?;
        Ok(Self {
            ctx: RefCell::new(ctx),
            key_handle,
            child_public,
            child_private,
            spki_der,
        })
    }

```python
def build_csr(
    *,
    attest_key: tuncore.AttestKey,
    noise_static_pub: bytes,
    cn: str,
) -> bytes:
    """Build and DER-encode a CSR for this device.

    Soft backend: the CSR is built+signed inside Rust (`rcgen`); no scalar
    crosses the FFI. TPM backend: the key cannot export a scalar, so the
    CertificationRequestInfo (TBS) is built here with ``cryptography`` and
    the signature is delegated to the TPM via ``attest_key.sign``. Both
    paths produce a structurally identical CSR (same SPKI algorithm, same
    critical ``id-dsm-noiseStaticBinding`` extension), so the offline CA
    workflow is unchanged.
    """
    if len(noise_static_pub) != 32:
        raise EnrollError(
            f"noise_static_pub must be 32 bytes, got {len(noise_static_pub)}"
        )
    import tuncore

    if getattr(tuncore, "ATTEST_BACKEND_IS_SOFTWARE", True):
        return bytes(attest_key.build_csr(cn, bytes(noise_static_pub)))
    return _build_csr_tpm(
        attest_key=attest_key, noise_static_pub=bytes(noise_static_pub), cn=cn
    )


def _build_csr_tpm(
    *,
    attest_key: tuncore.AttestKey,
    noise_static_pub: bytes,
    cn: str,
) -> bytes:
    """Assemble a PKCS#10 CSR whose signature is produced by the TPM.

    No private key is exported. ``cryptography`` shapes the TBS; the TPM's
    91-byte SPKI is substituted for the throwaway signer's SPKI (P-256 SPKI
    is a fixed 91 bytes and appears exactly once in the TBS); the TPM signs
    the substituted TBS; the final ``CertificationRequest`` SEQUENCE is
    assembled here.
    """
    from cryptography import x509
    from cryptography.hazmat.primitives import hashes, serialization
    from cryptography.hazmat.primitives.asymmetric import ec
    from cryptography.x509.oid import NameOID

    from dsm.crypto.cert import (
        DSM_NOISE_STATIC_BINDING_OID,
        encode_noise_static_binding_value,
    )

    tpm_spki = bytes(attest_key.public_spki_der())
    if len(tpm_spki) != 91:
        raise EnrollError(
            f"TPM attest SPKI is not the expected 91-byte P-256 SPKI "
            f"(got {len(tpm_spki)}); cannot assemble CSR"
        )

    throwaway = ec.generate_private_key(ec.SECP256R1())
    ext_value = encode_noise_static_binding_value(noise_static_pub)
    csr0 = (
        x509.CertificateSigningRequestBuilder()
        .subject_name(x509.Name([x509.NameAttribute(NameOID.COMMON_NAME, cn)]))
        .add_extension(
            x509.UnrecognizedExtension(DSM_NOISE_STATIC_BINDING_OID, ext_value),
            critical=True,
        )
        .sign(throwaway, hashes.SHA256())
    )
    tbs = csr0.tbs_certrequest_bytes
    throwaway_spki = throwaway.public_key().public_bytes(
        serialization.Encoding.DER,
        serialization.PublicFormat.SubjectPublicKeyInfo,
    )
    if tbs.count(throwaway_spki) != 1:
        raise EnrollError("internal: throwaway SPKI not uniquely locatable in TBS")
    tbs = tbs.replace(throwaway_spki, tpm_spki)

    sig = bytes(attest_key.sign(tbs))  # DER ECDSA-with-SHA256, produced in-TPM

    # AlgorithmIdentifier { OID 1.2.840.10045.4.3.2 } (ecdsa-with-SHA256).
    sig_alg = bytes.fromhex("300a06082a8648ce3d040302")
    bitstring = b"\x03" + _der_len(len(sig) + 1) + b"\x00" + sig
    body = tbs + sig_alg + bitstring
    csr_der = b"\x30" + _der_len(len(body)) + body

    # Self-check: re-parse + verify before handing the CSR to the operator.
    parsed = x509.load_der_x509_csr(csr_der)
    if not parsed.is_signature_valid:
        raise EnrollError("assembled TPM CSR failed self-verification")
    return csr_der


def _der_len(n: int) -> bytes:
    """DER definite-length encoding of a non-negative length."""
    if n < 0x80:
        return bytes([n])
    body = n.to_bytes((n.bit_length() + 7) // 8, "big")
    return bytes([0x80 | len(body)]) + body
```

```python
"""Enroll-time TPM reachability check (TPM backend only).

Surfaces an actionable error if the TPM is unreachable, rather than letting
a raw tss-esapi failure escape from deep inside ``AttestStore.generate``.
"""

from __future__ import annotations

import logging

log = logging.getLogger(__name__)


class TpmPreflightError(Exception):
    """The TPM is not reachable for enrollment."""


def preflight_tpm(tcti: str | None) -> None:
    """Confirm the TPM responds before provisioning. No-op on the soft
    backend. Raises ``TpmPreflightError`` with operator guidance on failure.
    """
    import tuncore

    if bool(getattr(tuncore, "ATTEST_BACKEND_IS_SOFTWARE", True)):
        return  # soft backend: nothing to preflight

    # A throwaway generate+zeroize is the cheapest end-to-end reachability
    # probe that uses the real provisioning path (create_primary/create/load).
    # It writes nothing to disk. If the TPM is unreachable or the Owner
    # hierarchy is password-protected, this raises and we translate it.
    try:
        probe = tuncore.AttestKey.generate()
        probe.zeroize()
    except Exception as e:  # noqa: BLE001 — top-level enroll boundary, re-raised typed
        where = tcti or "device:/dev/tpmrm0"
        raise TpmPreflightError(
            f"TPM not usable at {where}: {e}. Check that /dev/tpmrm0 exists, "
            "the user is in group 'tss' (or run via sudo), and the Owner "
            "hierarchy has empty authorization (v1 requires empty ownerAuth)."
        ) from e
```
